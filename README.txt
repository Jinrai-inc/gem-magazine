=== GEM-MAGAZINE WordPress テーマ ===

宝石鑑定の知識をやさしく学べる、宝石・ジュエリー専門メディア向けのクラシックテーマです。
トップページは「LINE無料講座への登録」を着地点に設計しています。

--------------------------------------------------
インストール
--------------------------------------------------
1. この「gem-magazine」フォルダを丸ごと ZIP 圧縮します。
   （フォルダ名＝テーマのスラッグなので、変更しないでください）
2. WordPress 管理画面 →「外観」→「テーマ」→「新規追加」→「テーマのアップロード」
   から ZIP をアップロードして「有効化」します。
   ※ FTP の場合は wp-content/themes/ 配下へ gem-magazine フォルダを置きます。

--------------------------------------------------
最初に行う設定
--------------------------------------------------
● トップページを「フロントページ」に
  「設定」→「表示設定」→「ホームページの表示」を “固定ページ” にし、
  投稿ページ（記事一覧）用の固定ページを指定すると、トップの「記事一覧へ」が
  正しくその一覧にリンクします。
  （front-page.php があるため、固定ページ未設定でもトップは表示されます）

● FV（ファーストビュー）の背景画像
  「外観」→「ヘッダー画像」から画像をアップロードします。
  推奨サイズ 1600×900px 程度。未設定時は淡いグラデーションが表示されます。

● LINE 友だち追加 URL とFVの文言
  「外観」→「カスタマイズ」→「GEM-MAGAZINE 設定」から、
  - LINE友だち追加URL（全ボタン共通）
  - ブランド英字 / ヘッダー説明文
  - FVの小見出し・見出し・本文・配信内容・ボタン文言
  を変更できます。

● メニュー
  「外観」→「メニュー」で以下の位置に割り当てられます（未設定でも既定表示あり）：
  - グローバルナビ
  - フッター：コンテンツ
  - フッター：メディアについて

● ロゴ
  「外観」→「カスタマイズ」→「サイト基本情報」→「ロゴ」で差し替え可能。
  未設定時はダイヤ型のSVGマークを表示します。

--------------------------------------------------
新着記事カードについて
--------------------------------------------------
トップ「新着記事」と各一覧は、通常の投稿から自動表示されます。
- サムネイル：投稿の「アイキャッチ画像」を使用。未設定の投稿は宝石風グラデーションで代替。
- カテゴリーラベル：投稿の最初のカテゴリー名を表示。

--------------------------------------------------
トップの固定セクションを編集したい
--------------------------------------------------
「はじめての方におすすめのコンテンツ」「3ステップ」「特典リスト」「選ばれる理由」は
inc/theme-data.php の各配列を編集してください。
（子テーマの functions.php で gem_content_cards / gem_steps / gem_trust / gem_benefits
  フィルターを使えば、本体を触らずに上書きできます）

--------------------------------------------------
ファイル構成
--------------------------------------------------
gem-magazine/
├─ style.css                 テーマ情報＋全スタイル
├─ functions.php             テーマ設定・カスタマイザー・記事カード
├─ header.php / footer.php   ヘッダー・フッター
├─ front-page.php            トップページ
├─ index.php                 記事一覧 / 検索 / アーカイブ（共通）
├─ single.php / page.php     記事 / 固定ページ
├─ searchform.php            検索フォーム
├─ assets/js/theme.js        検索開閉・モバイルメニュー・スクロール表示
├─ inc/icons.php             インラインSVGアイコン
├─ inc/theme-data.php        トップの固定セクション用データ
└─ template-parts/           LINE講座セクション・記事下CTA
